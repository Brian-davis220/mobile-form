# Mobile Forms

A React Native (Expo) registration form demonstrating how forms work in mobile apps.

## Features

- Text inputs for full name, email, phone, password and password confirmation
- Mobile keyboard types (`email-address`, `phone-pad`) and `secureTextEntry` for passwords
- Custom radio-button group for gender selection
- `Switch` for accepting terms and conditions
- Field validation with inline error messages
- `KeyboardAvoidingView` + `ScrollView` so the keyboard never hides inputs
- Shows the submitted data after a successful submission, plus a reset button

## Run it

```bash
npm install
npx expo start
```

Scan the QR code with the Expo Go app (Android/iOS), or press `a` for an Android emulator / `w` for web.
